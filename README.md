# NBA Playoff Monte Carlo Simulation

## Overview

This project uses Monte Carlo simulation techniques in Python to predict NBA Playoff outcomes based on regular-season head-to-head performance data. The model analyzes team matchups and simulates thousands of playoff scenarios to estimate advancement probabilities and identify potential championship outcomes.

## Objective

The purpose of this project is to apply statistical modeling, probability theory, and data analytics techniques to sports prediction. The simulation provides probabilistic forecasts rather than deterministic predictions, demonstrating how uncertainty can be incorporated into predictive models.

## Dataset

The model uses NBA 2024–2025 head-to-head regular season data stored in:

- nba_2024_25_head_to_head.xlsx

The dataset contains team matchup performance information used to calculate win probabilities for playoff simulations.

## Methodology

1. Import and clean matchup data.
2. Calculate team win probabilities.
3. Simulate playoff series outcomes.
4. Run Monte Carlo simulations repeatedly.
5. Aggregate results and calculate probabilities.
6. Identify likely playoff advancement paths and championship outcomes.
